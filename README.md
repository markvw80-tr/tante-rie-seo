# Tante Rie SEO

SEO-marketingteam voor tanterie.nl (Shopify). Spelregels, rollen en werkvolgorde staan in `CLAUDE.md`.

## Structuur

| Map | Inhoud |
|-----|--------|
| `.claude/agents/` | De acht rollen van het team |
| `marketing/` | Maandplannen (`plan-JJJJ-MM.md`) en `changelog.md` |
| `marketing/technisch/` | Technische audits |
| `marketing/zoekwoorden/` | Zoekwoordclusters |
| `marketing/content/` | Contentconcepten |
| `marketing/onpage/` | On-page voorstellen en backups |
| `marketing/autoriteit/` | Backlink-, concurrentie- en lokale briefs |
| `marketing/rapporten/` | Maandrapportages |
| `marketing/review/` | Oordelen van de kwaliteitsredacteur |
| `data/` | Ruwe exports: `gsc/`, `ga4/`, `ahrefs/`, `semrush/` |
| `assets/` | `afbeeldingen/` en `screenshots/` |
| `scripts/` | Hulpscripts (bulk-updates, exports) |
| `notities/` | Losse notities, besluiten, ideeën |
| `mailbox/` | Berichten tussen het SEO-team en het PIM-team (zie `mailbox/README.md`) |

Theme-code staat in `~/TanteRie-Theme-Editor`, niet hier.
